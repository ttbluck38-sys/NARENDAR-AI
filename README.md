# Narendar Hub

Offline-first Android student toolkit. No API keys, backend, login, Firebase, Supabase, or internet connection is required for the core app.

## Included
- Dashboard with score, streak and task summary
- Offline MCQ Quiz Arena with subjects and explanations
- Calculator and common study formulas
- Unit reference and multiplication tables
- Local notes
- Study planner and task tracking
- Progress and achievements
- Dark mode

## Build
The GitHub Actions workflow builds a debug APK and uploads `NarendarHub-debug-apk` as an artifact.

Package: `com.narendar.hub`
